# 🚀 Atli's Space Game

**Atli's Space Game** is an interactive early-literacy learning game designed to help young children build foundational reading skills through a fun space adventure.

The game takes children on a journey through the solar system, with each planet introducing a different early-reading skill. Children learn through short activities, visual illustrations, audio feedback, repetition, and an encouraging game experience.

## 🌎 Learning Journey

Children progress through the planets as they develop their reading skills:

| Planet | Skill |
|---|---|
| ☿ Mercury | Capital letters |
| ♀ Venus | Lowercase letters |
| 🌎 Earth | Uppercase and lowercase matching |
| ♂ Mars | Letter sounds / phonics |
| ♃ Jupiter | Reading simple words |
| ♄ Saturn | Missing letters |
| ♅ Uranus | Building simple sentences |
| ♆ Neptune | Reading a children's story |
| ♇ Pluto | Reading skills assessment |

## 📚 What Children Practise

The game focuses on foundational literacy skills including:

- Recognizing uppercase letters
- Recognizing lowercase letters
- Matching uppercase and lowercase letters
- Learning letter sounds
- Reading simple words
- Completing words with missing letters
- Building simple sentences
- Reading and following a short story
- Demonstrating learned skills through an end-of-journey assessment

## 🎮 Game Experience

Atli's Space Game is designed to make early reading practice feel like play.

Children:

- Explore planets
- Answer interactive questions
- Receive immediate encouraging feedback
- Build sentences
- Read illustrated story pages
- Progress through an adventure
- Complete a final literacy assessment

The game is designed to avoid punitive gameplay and instead encourage children to keep trying and learning.

## 👨‍👩‍👦 Parent-Focused Learning

The final Pluto assessment provides parents with a breakdown of the child's performance across the skills introduced throughout the game.

The assessment is intended as an **informational learning snapshot**, not a formal reading-level assessment or diagnosis.
